# AI Interview Preparation Platform

An AI-powered interview preparation platform that analyzes a candidate's resume, self-description, and target job description to generate a personalized interview report.

## Features

- User registration and login
- Resume PDF upload
- AI-powered interview report generation
- Technical interview questions
- Behavioral interview questions
- Skill-gap analysis
- Personalized preparation plan
- AI-generated resume PDF
- Secure authentication using JWT
- MongoDB database integration

## Tech Stack

### Frontend
- React
- Vite
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer

### AI
- Google Gemini API
